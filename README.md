# 📈 Page View Time Series Visualizer

A Python data visualization project built using **Pandas**, **Matplotlib**, and **Seaborn** to analyze and visualize freeCodeCamp forum page view trends over time.

## 🚀 Features

- 📅 Time Series Line Chart
- 📊 Monthly Average Bar Chart
- 📦 Year-wise Box Plot
- 📦 Month-wise Box Plot
- 🧹 Data Cleaning using Percentiles
- 📈 Trend & Seasonality Analysis

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
